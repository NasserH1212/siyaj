# Task 1.1 — Scaffold the repository

Owner: Nasser · Implementer: Claude Code · Reviewer: Codex · Branch: `task/1.1-scaffold`

## Context
First runnable skeleton of Siyaj. Every later task builds on it, so keep it small, clean, and reproducible in GitHub Codespaces.

## Do
1. Folder structure from AGENTS.md: `services/core/siyaj/` as a Python package with empty subpackages (`api`, `normalizer`, `detectors`, `orchestrator`, `risk`, `policy`, `vault`, `proxy`, `output_scanner`, `audit`). Add empty `services/ml_inference/` and `services/analytics_worker/` folders with a one-line README each.
2. `services/core/pyproject.toml` for Python 3.12 with pinned versions, and a FastAPI app in `siyaj/main.py`.
3. `GET /health` checks PostgreSQL (`SELECT 1`) and Redis (`PING`) with short timeouts (2 s max).
   - Both healthy: HTTP 200 `{"status": "ok", "db": "ok", "redis": "ok"}`.
   - Any failure: HTTP 503 with the failing component set to `"error"` (fail closed).
   - No versions, hostnames, or error details in the response.
   - This is the only unauthenticated endpoint. Auth arrives in Task 2.2.
4. `docker-compose.yml` with `postgres:16`, `redis:7`, and `core` (built from `services/core/Dockerfile`, slim base image, non-root user). Add healthchecks; `core` waits for healthy db and redis. Configuration comes from environment variables; commit `.env.example` only, and keep `.env` git-ignored.
5. `Makefile` targets: `up`, `down`, `test`, `lint` (ruff + mypy), and `security` (prints "added in Task 1.2" and exits 0 for now).
6. Tests with pytest: `/health` returns 200 when both dependencies are healthy, and 503 when Redis is unreachable. Unit tests use dependency overrides or fakes, with no real network.
7. `.github/workflows/ci.yml`: on push and pull_request, set up Python 3.12, install, then run `make lint` and `make test`.
8. README: add a short Quickstart (open in Codespaces, `make up`, `curl localhost:8000/health`). Keep the existing description.

## Acceptance criteria
- `make up`, then `curl -s -i localhost:8000/health` returns HTTP 200 with db and redis `"ok"`.
- `docker compose stop redis` makes `/health` return 503 with `"redis": "error"`.
- `make lint` and `make test` pass locally, and CI is green on the PR.
- No generated files are committed (`.venv`, `__pycache__`, `.env` are ignored).
